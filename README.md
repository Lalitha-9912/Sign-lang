# Sign Language Recognition System

## Overview

The **Sign Language Recognition System** is a web-based application designed to translate hand gestures into text using machine learning techniques. This project aims to bridge communication gaps for individuals with hearing impairments by providing a real-time sign language interpreter.

## Features

- **Real-Time Gesture Recognition**: Utilizes a webcam to capture hand gestures and translates them into text instantly.
- **User-Friendly Interface**: Simple and intuitive web interface for seamless interaction.
- **Lightweight and Efficient**: Optimized for performance, ensuring smooth operation even on devices with limited resources.

## Technologies Used

- **Python**: Backend programming language.
- **Flask**: Web framework for building the application.
- **TensorFlow.js**: For running machine learning models directly in the browser.
- **HTML/CSS**: For frontend development and styling.
- **JavaScript**: For dynamic content and interactions.

## Installation

To run this project locally, follow these steps:

1. **Clone the Repository**:

   ```bash
   git clone https://github.com/Lalitha-9912/Sign-lang.git
   cd Sign-lang
  ```

## Set Up Virtual Environment

```bash
python -m venv venv
source venv/bin/activate  # On Windows, use `venv\Scripts\activate`
```

## Install Dependencies

```bash
pip install -r requirements.txt
```

## Run the Application

```bash
python app.py
```

Open your browser and navigate to `http://127.0.0.1:5000` to access the application.

---

## Usage

- **Start the Application**: Run the application using the command `python app.py`.
- **Access the Interface**: Open a web browser and go to `http://127.0.0.1:5000`.
- **Use the Webcam**: Allow the application to access your webcam.
- **Perform Gestures**: Make hand gestures in front of the camera to see them translated into text.
